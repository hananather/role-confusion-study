# Evaluating using Mock Tool Calls to Quarantine Untrusted Prompt Inputs

Author: dgros. Published: 2026-06-05. Checked: 2026-09-04.

[Original post](https://www.lesswrong.com/posts/GPMZaRmxxNb8o2aGo/evaluating-using-mock-tool-calls-to-quarantine-untrusted-2)

**Reading note, not a full transcript.** Descriptions are paraphrases. Full-text preservation remains pending a supplied export.

This evaluation places untrusted judge inputs in tool messages. Across three judging tasks and seven models, tool wrapping does not consistently reduce attack success and sometimes increases it. The result challenges the assumption that moving text into the tool role reliably makes a model treat it as low-authority input.
