# My experiment plots

Start with my [curated figure library](../../../../../chart-library/index.html), which connects the selected plots to yesterday’s research goals and keeps the small/large offset comparisons central. I preserve the original files below as source artifacts.

I retain the paper's figure-specific colors, color meanings, TeX Gyre Termes font, small raw-token points, boxed panels and light grid. I use the authors' plotting recipes as the style reference; Matplotlib layout is not pixel-identical to the R renderer.

- [My measured September 11 gardening overview](my-h100-gardening-overview.png): the authors' conversation and Figure 7 layout, with probabilities from my H100 run. [Provenance](provenance.json).
- [My measured September 5 steering comparison](historical-steering/measured-sep5-steering-token-curves.png): 59 identical command tokens under baseline and both signs of the historical Tool-minus-User activation direction. This uses the earlier intervention site and probe, not the September 11 gardening setup. [Provenance and outcome summary](historical-steering/measured-sep5-steering-provenance.json).
- [My offline 1% vector-offset illustration](probe-offset-illustration/probe-offsets-1pct.png) and [5% illustration](probe-offset-illustration/probe-offsets-5pct.png): my saved September 11 activations scored after adding or subtracting raw User/Tool classifier directions. These are local arithmetic illustrations; there is no model continuation or behavioral measurement. [Method and limitations](probe-offset-illustration/README.md).

PDFs are alongside each PNG. I visually reviewed these figures and retained source checksums and plotted numeric data. I restored the paper style after Hanan's explicit September 11 correction; future renders use it by default.
