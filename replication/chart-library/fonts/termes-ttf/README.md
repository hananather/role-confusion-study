# PDF-compatible TeX Gyre Termes

These fonts preserve the authors’ TeX Gyre Termes design and metrics. I converted the installed OpenType CFF sources to TrueType quadratic outlines with fontTools Cu2QuPen, maximum error 0.25 font units (0.025% of an em), reversing contour direction. The purpose is valid CID TrueType embedding by Matplotlib, avoiding its CFF font-type mismatch warning. Original names, metrics and license metadata remain in the fonts. Source: /usr/local/texlive/2019/texmf-dist/fonts/opentype/public/tex-gyre/texgyretermes-{regular,bold,italic,bolditalic}.otf.
