# Canonical MATS dialogue v1

Hanan approved this as the reusable original MATS example. I preserve the User 1 → CoT 1 → Assistant 1 → User 2 → CoT 2 → Assistant 2 structure, original generated text, measured scores, paper palette, Termes typography and complete opening excerpts at 35 degrees.

Use `figure.pdf` for vector publication output and `figure.png` for previews. `conversation.md` contains all six passages and the reading note on the model’s advice. `manifest.json` freezes the files and their identities. New measurements or changes to the dialogue belong to a new version; they must not silently replace this example. The data files remain available for future comparisons, with the model/probe/runtime boundary recorded in `provenance.json`.
