# Authored MATS conversations for the six-passage illustration

I use this fixed set of twelve original conversations to select a readable illustration of the role-probe measurement. Each candidate has the same six-passage structure: User 1, CoT 1, Assistant 1, User 2, CoT 2, Assistant 2. The measurement harness adds its separately recorded system message.

All passages are authored fictional input, including the reasoning-style passages and answers. They are neither outputs generated by the evaluated model nor quotations from Neel Nanda. The conversations discuss general research choices; they make no claims about current MATS admissions requirements or Neel's private views.

This is a Distill task. My north star is an illustration that makes the measurement understandable from its text, with clear writing, inspectable inputs, and truthful selection disclosure. I retain every candidate and result; choosing the most legible graph does not make it a representative sample. Any aggregate conclusion needs a separately defined evaluation and aggregation rule.

## Files

- [Candidate conversations](candidates.json): the twelve complete inputs, fixed before model measurement.
- [Freeze record](candidates-freeze.json): creation time, file and candidate hashes, and passage word counts.

I will not alter these inputs after inspecting their scores. Any later set must have a new directory and an explicit revision record.


## Completed measurements and selected figure

All 12 candidates completed, with three formatting conditions each. The local run used one cached model, 36 forwards, 80.7 seconds including loading and a 12.76 GB peak allocation. No continuation was generated. The numerical [audit](audit.md) passed for all candidates.

I selected **mats-03** after visual inspection, because its six text excerpts fit cleanly and its blue, amber and green patterns are visible across the formatting conditions. The selection is for illustration, not maximum role separation or representativeness. The [selection record](selection.json) and all candidate data remain available.
